# VolleyVision

Volleyball analytics platform — ball tracking, trajectory analysis, hit detection, and a web dashboard for coaches and players.

Built on YOLOv8 + Kalman filter for ball tracking, with a data pipeline that exports per-frame JSON for downstream analysis and visualization.

---

## Quick Start

```bash
pip install -r requirements.txt
python main.py video path/to/match.mp4
```

The first run will prompt an interactive calibration window — click the left and right net poles (9 m) and the top and bottom of the net (1 m) to enable real-world speed readings in km/h. Press **S** to skip and use pixel/s instead.

---

## CLI Reference

```bash
python main.py video <input> [options]
```

| Flag | Default | Description |
|------|---------|-------------|
| `--output` | `output/` | Directory for tracked video and data files |
| `--model` | `models/best3.pt` | Path to YOLO weights |
| `--conf` | `0.40` | Detection confidence threshold |
| `--trail-len` | `40` | Ball trail length in frames |
| `--no-preview` | off | Disable real-time preview window |
| `--raw` | off | Show raw YOLO boxes (no Kalman / trail) |
| `--net-width-px` | — | Net width in pixels (skips interactive calibration) |
| `--net-height-px` | — | Net height in pixels (skips interactive calibration) |

## Dashboard

```bash
pip install flask
python dashboard/app.py
# → http://127.0.0.1:8000
```

The dashboard reads from `output/` and shows:
- Clip library with poster thumbnails
- Video player with the tracked overlay
- Metrics strip — peak speed, avg speed, apex height, tempo, track rate
- Ball speed over time chart
- Ball path canvas with apex and contact markers

The dashboard requires `.clip.json` files generated by the integration pipeline. If you have existing tracked videos without JSON data, run the backfill script:

```bash
# Single clip
python -m integration.scripts.backfill_json tests/test27.MP4

# All videos in tests/
python -m integration.scripts.backfill_json --all
```

## Output Files

Each processed video produces three files in `output/`:

| File | Description |
|------|-------------|
| `<stem>_tracked.mp4` | H.264 video with ball trail, HUD overlay, and original audio |
| `<stem>.clip.json` | Full per-frame trajectory, detections, events, and metrics |
| `<stem>.poster.jpg` | Thumbnail from first frame |
| `manifest.json` | Index of all clips — read by the dashboard |

### clip.json schema

```
schema: "vv-clip/1"
trajectory[]   per-frame Kalman position (x, y normalized 0–1), velocity, speed
detections[]   raw YOLO detections (sparse)
events[]       apex and contact events with timestamps
metrics        peak_speed_kmh, avg_speed_kmh, apex_m, tempo_s, track_continuity
calibration    px_per_m, net dimensions, homography (reserved)
pose[]         skeleton data (reserved — MediaPipe, coming)
```
